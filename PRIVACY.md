# Privacy Policy – Coach UdeA

Coach UdeA is a personal educational tool used for clinical exam preparation.

## Data Collection
The system stores learning-related data such as:
- Study sessions
- Errors and biases
- Flashcards
- Review schedules

No personal identifying information (PII) is collected.

## Data Usage
All data is used exclusively to improve the learning process of the user.

## Data Sharing
No data is shared with third parties.

## Data Storage
Data is stored locally or on private infrastructure controlled by the owner.

## Contact
This project is for personal educational use.
